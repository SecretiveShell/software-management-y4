# Chatbot wireframe

A chatbot-only wireframe for John Jones Printers customer support.

It uses the same 1280 × 720 frame as the low-fidelity wireframe and keeps the same grey, dashed, Arial visual language, with a small amount of John Jones Printers branding.

## Open it

```sh
xdg-open wireframe/high-fidelity/index.html
```

The chat pane is the whole deliverable. There is no shop, header, footer, sidebar or other website around it. A list of valid seed messages sits outside the 720p frame, in the page border to the left, so each intent can be sent with one click.

## Detached scenario controls

Open the separate controls page:

```sh
xdg-open wireframe/high-fidelity/controls.html
```

The controls page lists every chat state and opens it in a new tab. It stays detached from the chat pane.

## States

- Welcome
- Live chat
- Product results
- No reliable answer
- Transferring to a human
- Human joined
- Humans offline
- Assistant offline
- Voice call
- Help centre
- Transfer unable / address change
- Returns
- Video answer

Each state can also be opened directly:

```text
index.html?scenario=welcome
index.html?scenario=chat
index.html?scenario=products
index.html?scenario=no-answer
index.html?scenario=transferring
index.html?scenario=human-joined
index.html?scenario=humans-offline
index.html?scenario=offline
index.html?scenario=voice
index.html?scenario=faq
index.html?scenario=address
index.html?scenario=returns
index.html?scenario=video
```

## Chat interactions

- Send messages with the composer or Enter.
- Use suggested prompts and quick replies.
- Ask for a human and watch the transfer queue.
- Cancel a transfer or let the human agent join.
- Open product details, change quantity and add to cart.
- Use feedback controls and source links.
- Attach a file.
- Open the help centre and search the FAQ.
- Start and end a simulated voice call.
- Play the troubleshooting video.
- Download a transcript.
- Use the offline and retry states.

## Notes

- Chat replies are scripted from keyword intent, not generated by an AI model.
- Human handoff joins after a short delay so the state is easy to demonstrate.
- Voice and video are UI simulations.
- The chat is intentionally the only thing on the page; scenario controls live in `controls.html`.
